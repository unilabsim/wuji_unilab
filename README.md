# Wuji UniLab

Wuji Hand reorientation training on UniLab, using the mjwarp physics backend.

Development is tracked in [roadmap #1](https://github.com/unilabsim/wuji_unilab/issues/1).
This bootstrap commit establishes the parent integration base; it does not yet
provide an installed task or claim training support.

Wuji model assets belong in this repository. UniLab, UniSim, and unilab-rl remain
upstream dependencies. Development does not publish packages or modify upstream
main branches.
